# PDF压缩

一款适用于 Apple 芯片 Mac 的本地 PDF 压缩工具。给每份文件设定大小上限，先比较压缩效果，再导出成品。

**当前版本 V1.2**

**[下载 Mac 应用](https://github.com/ZhichenGu/Pdf-Squeezer/releases/latest)** · macOS 14 或更高版本 · Apple Silicon（M 系列）

## 安装

在 Release 的 **Assets** 中下载名称以 `macOS-arm64.zip` 结尾的文件，解压后将 **PDF压缩.app** 拖入「应用程序」。运行所需的 Python 和依赖已随应用打包。

### 首次打开时被 macOS 拦截怎么办

当前版本使用本地签名，尚未经过 Apple 公证。首次打开时，macOS 可能提示“无法验证开发者”或“Apple 无法验证此 App 是否包含恶意软件”。

确认安装包来自本仓库的 Release，并信任其来源后，可以按以下步骤操作：

1. 解压下载包，将 **PDF压缩.app** 拖入「应用程序」，双击尝试打开。
2. 如果出现上述拦截提示，先关闭提示，再打开 **「系统设置 → 隐私与安全性」**。
3. 向下找到「PDF压缩」被阻止打开的提示，点击 **「仍要打开」**。
4. 按系统提示使用 Touch ID 或输入这台 Mac 的登录密码，并确认打开。

这些操作由使用软件的同事在自己的 Mac 上完成。若找不到「仍要打开」，可先再尝试打开一次应用，再回到该设置页面。公司管理的电脑若禁止手动允许打开，请联系 IT 管理员。

应用适用于 **Apple 芯片（M 系列）Mac、macOS 14 及以上**。完整操作说明见 [Apple 官方支持](https://support.apple.com/zh-cn/102445)。

## 使用

1. **添加文件**。把一份或多份 PDF 拖到左侧，勾选要处理的文件。点击文件名即可在右侧翻页预览。
2. **设置目标**。在左侧每份文件右侧填写「目标 MB」，例如作品集 10 MB、简历 2 MB。「批量设定」可给选中的文件统一填值。大小按十进制计算，1 MB 为 1,000,000 字节。
3. **比较画质**。打开「设置」调整图片质量和 DPI，等当前文件完成试压后，可查看实际大小，并拖动分隔线比较原稿与试压结果。
4. **压缩与导出**。点击「压缩所选文件」。超限时，面板列出目标、实际大小和差额，可以按实际大小导出、调整参数，或尝试强力压缩。强压会把页面画面转成图片，同时保留可搜索文字和链接；放大时小字和细线可能变软。确认效果后，可单份或批量导出。

V1.2 会在找到达标参数后继续搜索更高的画质；若达到常规压缩下限仍超标，可通过提示面板选择强压。预览上方的「文件组成」显示图片、字体、文字与矢量等数据流的占比，用于判断体积来源，占比不包含 PDF 容器开销。

处理中可点击「停止任务」，保留已经完成的成品。出现失败后可点「重试失败文件」，沿用普通压缩或强压方式重新处理。新一轮失败或取消时，上次成功结果仍可导出。

质量、DPI、开关和导出目录会自动记忆。文件队列、独立目标、勾选状态、所在页和成功结果会在下次打开时恢复；结果存放在本机的应用支持目录。原件移动或删除后不会恢复该项目，原件发生修改时会重新处理。

压缩在本机完成。原件保留，导出文件重名时自动追加编号。单份目标可能受可压缩程度限制，应用会显示实际字节数对应的结果。

## 超链接

应用会检查 PDF 链接注释和内部跳页。点击预览区的「链接」可查看所在页和异常地址。只有主动选择「检测网址」才会访问文档中的网页；需要登录、服务器拒绝访问或网络超时都会显示相应提示。

## 从源码构建

在 Apple Silicon Mac 上准备 Xcode 命令行工具和 Python 3，然后在仓库根目录运行：

```sh
/usr/bin/python3 scripts/build.py
```

构建完成后可以运行回归检查：

```sh
bash scripts/test.sh
```

检查包括已达标文件参数生效、目标内搜索、资源清理、链接与可搜索文字保留、停止、失败重试及会话恢复。测试使用合成文件，不包含用户文档。

首次构建会下载锁定版本的 CPython、Pillow 和 pypdf，并逐项验证 SHA-256；后续构建复用缓存。应用、Release ZIP 和校验文件位于 `dist/`。

`Sources/` 包含 SwiftUI 界面、PDF 预览和页面渲染器，`Workers/` 包含常规压缩、强力压缩和链接检查。界面版本号取自 `Resources/Info.plist`。维护者发布新版时，更新该版本号并将对应的 `releases/v版本号.md` 合入 main，发布工作流会构建并上传下载包。
