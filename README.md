# PDF压缩

一款适用于 Apple 芯片 Mac 的本地 PDF 压缩工具。给每份文件设定大小上限，先比较压缩效果，再导出成品。

**[下载 Mac 应用](https://github.com/ZhichenGu/Pdf-Squeezer/releases/latest)** · macOS 14 或更高版本 · Apple Silicon（M 系列）

## 安装

在 Release 的 **Assets** 中下载名称以 `macOS-arm64.zip` 结尾的文件，解压后将 **PDF压缩.app** 拖入「应用程序」。运行所需的 Python 和依赖已随应用打包。当前发行包使用本地签名，未经过 Apple 公证，首次打开时 macOS 可能提示无法验证开发者。

## 使用

1. **添加文件**。把一份或多份 PDF 拖到左侧，勾选要处理的文件。点击文件名即可在右侧翻页预览。
2. **设置目标**。在预览区右上方填写当前文件的「单份目标」，例如作品集 10 MB、简历 2 MB。「批量设定」可给选中的文件统一填值。若提交平台还限制附件总量，勾选「限制所选文件的合计大小」。大小按十进制计算，1 MB 为 1,000,000 字节。
3. **比较画质**。打开「设置」调整图片质量和 DPI，等当前文件完成试压后，可查看实际大小，并拖动分隔线比较原稿与试压结果。
4. **压缩与导出**。点击「压缩所选文件」。超限时，面板列出目标、实际大小和差额，可以按实际大小导出、调整参数，或尝试强力压缩。强压会把页面画面转成图片，同时保留可搜索文字和链接；放大时小字和细线可能变软。确认效果后，可单份或批量导出。

压缩在本机完成。原件保留，导出文件重名时自动追加编号。单份目标和合计上限都可能受可压缩程度限制，应用会显示实际字节数对应的结果。

## 超链接

应用会检查 PDF 链接注释和内部跳页。点击预览区的「链接」可查看所在页和异常地址。只有主动选择「检测网址」才会访问文档中的网页；需要登录、服务器拒绝访问或网络超时都会显示相应提示。

## 从源码构建

在 Apple Silicon Mac 上准备 Xcode 命令行工具和 Python 3，然后在仓库根目录运行：

```sh
/usr/bin/python3 scripts/build.py
```

首次构建会下载锁定版本的 CPython、Pillow 和 pypdf，并逐项验证 SHA-256；后续构建复用缓存。应用、Release ZIP 和校验文件位于 `dist/`。

`Sources/` 包含 SwiftUI 界面、PDF 预览和页面渲染器，`Workers/` 包含常规压缩、强力压缩和链接检查。界面版本号取自 `Resources/Info.plist`。维护者发布新版时，更新该版本号并将对应的 `releases/v版本号.md` 合入 main，发布工作流会构建并上传下载包。
