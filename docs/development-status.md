# 当前开发状态

更新于 2026-11-15。

- 本机开发版本为 V1.3，安装位置为「应用程序 / PDF压缩.app」。
- 公开 GitHub Release 为 V1.2。V1.3 尚未推送和发布。
- 本轮按《macOS小工具与插件开发基准》整理界面，保留独立目标、批量填写、试压、比较、链接检查、停止、重试和任务恢复。

## V1.3 已完成

- 文件行展示原始大小、压缩后大小、状态图标与文字。目标输入错误在本行显示，失败文件提供就近重试。
- 左右分栏可拖动，标题区与文件行收紧。进度、停止、压缩、导出使用固定的操作区。
- 预览模式位置固定，暂不可用的模式禁用。质量与 DPI 的批量作用范围、当前试压文件在设置中明确展示。
- 文件组成收进「文件详情」。
- 同一页缩放重绘时保留已渲染画面，切换文件或页面时显示加载状态。比较手柄独立处理拖动，页面滚动保持可用。
- 导出完成使用窗口内提示，支持直接在 Finder 中显示。超限文件在导出入口确认后继续处理。

## 验证

- 五项 PDF 工作器回归检查通过。
- 模型检查通过，包括设置记忆、已达标文件试压、失败保留结果、文件行重试、停止、会话恢复、导出内容一致、重名处理及超标导出确认。
- 本机界面检查通过，包括行内目标错误、收窄分栏、比较模式缩放、拖动比较手柄、正常导出提示及 Finder 文件定位。
